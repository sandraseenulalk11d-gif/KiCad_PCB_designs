# ESP32 30A Home Automation Controller

A custom industrial-grade controller board featuring ESP32 control, optoisolated relay driving, and GSM connectivity.

## Specifications & Features
- **Microcontroller:** ESP32-WROOM-32 (Wi-Fi / BLE)
- **Power Switching:** 30A high-power relays with PC817 optocoupler isolation
- **Cellular Connectivity:** SIM800 / Mini-SIM socket integration
- **Protection:** Flyback diodes, TVS diode arrays on I/O, and creepage isolation slots

- `/Design_files_30AHA`: KiCad schematic (`.kicad_sch`) and layout (`.kicad_pcb`)
